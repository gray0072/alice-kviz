# 08. Развитие

Идеи после MVP, примерно по убыванию пользы. Игра вдвоём на одной колонке не планируется:
у каждого ребёнка своя колонка.

## v1.1 — контент

- Довести банк до 200 вопросов (сейчас 165): новые места (каток, лагерь, парикмахерская, стоматолог, автомойка,
  праздник в детском саду, школьный концерт, поликлиника с прививкой у младшего брата),
  новые темы (деньги и карманные расходы, экология, бережное отношение к вещам).
- Тематические игры: «Алиса, запусти „Папин квест“ про школу» — фильтр по набору или теме.
- Поле `tts` у вопроса, когда нужно поправить ударение или паузы, не трогая текст.

## v1.2 — звук и атмосфера

- Звуки победы и ошибки (уже есть, `SOUNDS=1`), джингл в начале.
- Разные голосовые эффекты для вредных советов (`<speaker effect="…">`, проверить список в документации).
- Свои аудиофайлы через раздел «Ресурсы» консоли Диалогов.

## v1.3 — для родителей

- «Алиса, спроси навык „Папин квест“, как играли дети» → статистика по колонке: сколько игр,
  средний счёт, темы с ошибками. Хранится в `application_state` (сжатые счётчики).
- Еженедельные новые вопросы и выбор «вопрос дня».

## Технический долг

- Морфология: сейчас пересказ сравнивается по 5-буквенным основам. Если на колонке будет много
  переспросов, подключить стеммер (например, Snowball для русского) или использовать
  `request.nlu.tokens` и интенты Диалогов с грамматиками.
- Отдельный `tts` для вариантов с цифрами или аббревиатурами.
