# AGENTS.md

> 🇬🇧 Rules for contributors and AI agents. The primary language of this repo is Russian (the game
> speaks Russian); English is the second language and must be kept up to date where listed below.

«Папин квест» — приватный навык Яндекс Алисы: голосовой квиз о жизненных ситуациях для детей 6–10
лет. Код — бессерверная функция Yandex Cloud Functions на Node.js 18+ без внешних зависимостей.
Обзор и инструкция по развёртыванию — [README.md](README.md), спецификация — [docs/](docs/).

## Языки репозитория

Основной язык — **русский**: игра звучит по-русски, её делают и проверяют русскоязычные. Но репозиторий
публичный, и англоязычный посетитель должен с первого взгляда понять, что это и почему всё по-русски.
Английский — второй язык.

| Что | Язык |
|---|---|
| Вопросы (`data/questions/`), реплики Алисы (`src/phrases.js`, `src/reactions.js`), места и темы (`data/places.js`) | только русский: это то, что слышит ребёнок |
| Спецификация `docs/`, комментарии в коде, сообщения в консоли и тестах | русский |
| Идентификаторы, ключи состояния, имена файлов | английский (как сейчас) |
| `README.md` | русский, но **первый абзац под заголовком — на английском**: что это за проект, что он на русском и ссылка на `README_en.md` |
| `README_en.md` | английский перевод `README.md`, голосовые команды даются по-русски с переводом в скобках |
| Описание и topics репозитория на GitHub | сначала английская фраза, потом русская |
| Сообщения коммитов | одна строка на английском, чтобы историю читали все |

Правило синхронизации: **меняешь `README.md` — в том же коммите обнови `README_en.md`** (разделы,
команды, шаги настройки, таблицы, схемы). Переводить `docs/` не нужно.

## Команды

```bash
npm test            # автотесты (node:test), должны проходить всегда
npm run validate    # проверка банка вопросов: поля, уникальные id, длины, ответ ≤ 1024 символов
npm run play        # игра в терминале (-- --tts, -- --seed 42)
npm run catalog     # пересобрать docs/05-content-catalog.md
npm run pack        # validate + сборка dist/alice-kviz.zip для Yandex Cloud
```

`npm install` не нужен: зависимостей нет и не должно появляться. Нужна библиотека — сначала
обсудите, архив загружается в облако вручную.

## Правила изменений

- **Вопросы** пишутся строго по [docs/04-content-guide.md](docs/04-content-guide.md): без рода,
  короткие, три варианта (`right` / `trick` / `silly`) с разными ключевыми словами, без чисел «один /
  два / три» в вариантах. После правки: `npm test && npm run validate && npm run catalog`.
- **`id` вопросов не меняются и не переиспользуются**: история недавних вопросов на колонках хранит
  именно id. Первая цифра id — набор (1 школа, 2 дом, 3 город, 4 путешествия, 5 друзья, 6 семья).
- `docs/05-content-catalog.md` генерируется (`npm run catalog`), руками не правится.
- Ответ Алисе — не больше 1024 символов в `text` и `tts`; `session_state` < 500 байт. Это проверяют
  тесты и `validate`, не ослабляйте проверки.
- Меняется поведение диалога — обновите [docs/03-dialog-flow.md](docs/03-dialog-flow.md) и тесты;
  меняется формат состояния или протокол — [docs/06-tech-spec.md](docs/06-tech-spec.md).
- В архив попадают только `index.js`, `package.json`, `src/`, `data/` (см. `tools/pack.js`).
  `dist/` в `.gitignore`; иконка навыка лежит в `assets/`.
- Навык не собирает персональные данные: не спрашивает имён и ничего не отправляет наружу.

## Развёртывание

Автоматического деплоя нет. Обновление: `npm run pack` → Yandex Cloud → функция `alice-kviz` →
Редактор → загрузить `dist/alice-kviz.zip` → Сохранить. Переопубликовывать навык в Яндекс Диалогах
не нужно. Схема и пошаговая инструкция — в [README.md](README.md#как-это-устроено).
